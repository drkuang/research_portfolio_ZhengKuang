# Zheng Kuang — Research Portfolio

A static GitHub Pages portfolio for my PhD applications. It presents a dual **computational** and **experimental** research background — single-cell & spatial multi-omics, cell–cell communication and CRISPR screening on the computational/informatics side, and functional validation in tumour immunology and stromal-cell biology on the wet-lab side.

## Files

- `index.html`: main portfolio webpage
- `CV_ZhengKuang.pdf`: curriculum vitae
- `Squidpy_NotebookZhengKuang_shared_cleared.ipynb`: spatial-transcriptomics analysis workflow (outputs cleared)
- `assets/computational/`: bulk / single-cell / spatial-omics computational figures
- `assets/experimental/`: wet-lab validation figures
- `assets/squidpy/`: representative Squidpy spatial-analysis results (published example datasets)
- `assets/award_*.png`: certificates of awards
